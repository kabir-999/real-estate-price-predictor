# 🏡 Real Estate Price Predictor

🚀 A dynamic, ML-powered web app that predicts real estate property prices based on user-provided data such as location, area, BHK, and more. Built using Flask, this project bridges the gap between raw housing data and actionable pricing insights.

🔗 **Live Demo**: [Check it out here](https://real-estate-price-predictor-8x2l.onrender.com) 

---

## 📌 Features

- 📍 Predicts property prices based on inputs like area, location, and number of bedrooms
- 🧠 Trained ML model integrated with a clean Flask backend
- 🎨 Intuitive UI with real-time form validation
- ⚡ Fast predictions and responsive design
- 🧹 Outlier handling and data preprocessing for better accuracy

## 📊 Model Details

- Dataset: Preprocessed housing data scraped and cleaned for modeling
- Model Used: Linear Regression (can be extended to Decision Trees, Random Forests, etc.)
- Evaluation: RMSE used to validate prediction accuracy
- Custom logic for location encoding and feature transformation
